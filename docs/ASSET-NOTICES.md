# 素材与许可 / Asset notices

公开源码与重新许可是两件事。本次整理未将仓库中的所有代码、字体、图片和音乐封面统一授予 MIT。原有 [SOURCES.md](../SOURCES.md)、依赖许可与素材署名继续适用。

Public source visibility does not relicense every asset. Existing provenance, dependency licenses and notices remain applicable.

| --- | --- |
| Three.js | 上游 MIT，保留各自声明 / Upstream MIT |
| React Bits adapted glass work | 见 public/licenses/react-bits.txt，保留 MIT + Commons Clause 声明 / Preserve supplied notice |
| Wabi reference implementation | 见 SOURCES.md 中的来源与快照说明 / See source notes |

| Fonts | 按各字体原许可使用，不把字体本身当作项目代码 MIT / Font-specific terms apply |
| Avatar photo | 用户提供的照片，本次未修改 / User-supplied, unchanged |
| README cover | AI 概念插图，非实物照片或应用截图 / AI concept illustration |
| docs/images | 实际公网浏览器截图 / Actual public-page captures |

需要提取或重新分发特定第三方素材时，先核对该素材对应的来源和许可。现有来源说明不完整的部分仍应继续补齐，不能用仓库公开状态替代素材授权记录。

Check source-specific terms when extracting or redistributing third-party assets. Incomplete provenance should be improved; public visibility is not a substitute for asset licensing records.
