# 2026-10-30 · 浏览器边缘与恢复页面

## 本次变更

- 删除覆盖网页顶部的 `.chrome-safe` 色带。开屏期间 HTML、body、浏览器主题色统一为蓝色，擦除开始后恢复日夜底色。

- 新增 sitemap，robots 声明站点地图。
- GitHub 中英文 README 首图改为 ASCII + Dither 风格，旧统计图保留。

## 验证与边界

- 生产构建通过。既有 11 项测试和新增 6 项静态路由测试通过。
- 手机视口 390 × 844：开屏连续采样 219 帧，白天未出现黑色 HTML/body 底色，开屏蓝色同步；日夜页面、减少动态效果、404 返回正常。
- 桌面视口 1440 × 1000：404 无横向溢出。
- 实际中断主场景文件与入口脚本请求，均出现可见恢复界面；恢复请求后点击重试可回到页面。
- Twitterbot、微信、OpenGraph、Telegram 请求的静态标签、图片 GET/HEAD、PNG 尺寸、robots 检查通过。
- **尚未在 iPhone/Android 的 X 内置浏览器真机验收。没有发送推文，不能宣称 X 已显示缩略图。** 原站抓取检查已经通过，缺图的确切平台侧原因仍未确认。新的分享入口和图片地址提供重新抓取的路径，不保证清除 X 的缓存。
