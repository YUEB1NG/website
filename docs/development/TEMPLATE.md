# 开发记录模板 / Development record template

每次开源交付填写可核实字段，缺失写“未记录”，不得估算补齐或从 token 数推算时间。只公开经过筛选的汇总信息。

## 快照

- 项目与公开链接：
- 统计截止时间与时区：
- 首次开始与截止记录：
- 数据来源：
- 范围：主对话 / 关联子任务是否计入
- 数据文件与展示图片：

## 使用量

| 字段 | 数值 |
| --- | --- |
| 累计 token | 未记录 |
| 输入 / 缓存输入 / 非缓存输入 | 未记录 |
| 输出 / 其中推理输出 | 未记录 |
| 对话轮数 / 工具调用 / 失败调用 / 上下文压缩 | 未记录 |
| 已计时轮数 / 总轮数 | 未记录 |
| 对话跨度 / 活动时长 | 未记录 |
| 工具 / 模型相关 / 无法归类时间 | 未记录 |

明确输出的包含关系、缓存口径、估算项、日志缺失及异常。实际账单与估算费用必须分开。

## 交付证据

- 实现内容与未完成项：
- 实际验证的命令、结果和日期：
- GitHub commit / CI：
- 公网部署状态与验证：
- 真机测试状态：
- 开源依赖、素材来源、许可：
- 临时文件清理方式、文件名和大小：

## 隐私检查

不得提交密码、API Key、访问令牌、Cookie、私钥、验证码、授权二维码、带密钥的 URL、原始聊天/工具日志、非公开账号或个人信息、本机私有路径。配置文档只写变量名、用途、申请/设置方法与占位符，不写真实值。图片和元数据同样需要检查。

只提交允许公开的聚合数据。先做暂存区检查再推送。数据不可得时不为补齐表格导出敏感日志。
