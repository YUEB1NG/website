## 交互

- 上拖底部透明圈、点击 Start / 圆圈，或 Enter / ↑ 进入。点击星体回到透明圈，再次点击依次探索八大行星、月球和太阳。
- 全部星体恢复上一版写实纹理、地球云层／夜景灯光及原生星环，以 0.045 rad/s 缓慢自转。长按 550ms 或按 O，将同一组头像连续移入水平椭圆轨道；再次长按释放。前排从球体下半部经过，后排从上方绕回；按投影弧长均匀排布，近处稍大、远处稍小，原生星环入轨时退场。
- 点击模糊姓名，3秒后显示头像和悦饼，之后每3000毫秒在英文名与头像／悦饼之间切换。头像切换白天／动态星空，保存当前选择。悦饼为普通文字，月饼点击效果已删除。日夜头像外框使用同样的2px留白，底色跟随页面。
- 点击 like，使用提前准备的足球及复用的粒子缓冲；旧球散开后完全隐藏，当前球体散成1500颗表面采色粒子，再于约2.15秒内重组为下一款历届世界杯球形足球：1930–2026 每届代表款及1930两种决赛用球，共24款，按年份从近到远：2026 Trionda → 2022 Al Rihla → … → 1930，1930两款保留独立条目。它们是参照实物的原创风格化模型，并非官方纹理或精确工业模型。
- There 是普通文字，点击奖杯效果已移除。
- everything 保持普通文字，无点击特效。
- 点击漂浮或入轨的小图标，会弹出用户提供的阿根廷贴纸，每次5张，29种图案轮换，保留透明背景和原始宽高比。键盘可通过 Celebrate 按钮操作。
- Learn 点击前静止；点击1秒后变为Build，之后每2222毫秒切换一次Build／Share／Learn，淡出／淡入各0.3秒包含在计时内。整词固定宽度，不拆字。
- 下拖时 X 链接随手势提前淡出，避免被三行文字覆盖。全页禁用长按文字复制菜单。
- 系统减少动态效果会停下旋转和循环、跳过足球粒子过渡；姓名延迟3秒、Learn延迟1秒单次显示，保留点击操作。

## 文件与验证

`src/main.ts` 管理手势和文字；`scene.ts` 保留星空／棱镜并计算漂浮路径；`planets.ts` 在同一个 Three.js 场景渲染星体和头像；`football.ts`、`football-transition.ts`、`portrait-orbit.ts`、`stickers.ts` 分别提供足球、粒子重组、轨道排布和贴纸。透明圈与星体共用球心和半径，通过材质渐变衔接。

`python -X utf8 tests/browser-smoke.py` 执行当前完整交互检查（需先连接 agent-browser）；`tests/orbit-smoke.py` 检查长按与拖拽手势。截图和验证记录放在忽略目录 `artifacts/`。真实 iPhone Safari 尚未实机验证。

## 本地独立运行

项目位于 `D:\Projects\yueb1ng-wabi`，使用独立安装的 `D:\nodejs\node.exe`。`python -X utf8 run-local.py` 启动独立预览进程；关闭终端或桌面应用不会终止该进程。`python -X utf8 run-local.py --stop` 停止本项目的预览。日志和 PID 只放在项目 `artifacts/` 目录中。

网站构建产物是标准静态文件 `dist/`，可由任何静态 HTTP 服务托管；线上网站不依赖本机预览进程。`.openai/hosting.json` 仅是当前发布渠道的配置，不是网站运行依赖。

玻璃有两束独立游动的柔光，慢速与不同轨迹，不绑定模型旋转；减弱色散与拖动弹性。回到透明圈后停止隐藏的 Three.js 绘制，Three.js 可用时不再上传冗余二维粒子画布。
